### Added
- **The dev dashboard can show Android downloads.** The `store-stats` function now also reads Google Play's installs report (the Play Console's bulk reports in its Cloud Storage bucket, with a read-only service account) and writes the days to `store_stats` as `android`, next to iOS: the last 30 days the first time, then what is missing. The number is "Daily User Installs" - the users who installed the app that day - the nearest thing Play has to the iOS first downloads. A day Google has not written yet is a dash, never a zero.
- **What to set up is in `docs/ANDROID-DOWNLOADS-DIN-OPGAVE.md`:** the report bucket, a service account with "View app information and download bulk reports" in the Play Console, and the function's secrets `PLAY_SERVICE_ACCOUNT_JSON` and `PLAY_REPORTS_BUCKET`. Until both are set the function skips Android and says so; iOS is not touched, and a failure on one store never takes the other's numbers with it.
- `npm run test:store-stats-android` runs the new code against a made-up Google and a made-up UTF-16 report.
