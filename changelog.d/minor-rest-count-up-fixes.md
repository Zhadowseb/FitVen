### Changed
- **Unticking a set takes the rest counted after it away.** The number under a set that the app counted (not one you typed or planned) is a record of the time after that tick, and the tick is gone: the field is empty again, and ticking the set again counts up again. A planned rest is never touched.
- **Sets ticked off within 15 seconds of each other share the rest.** Somebody who did a few sets and ticked them off late has not rested for the whole stretch after one set. The time since the tick before the burst is shared equally between that set and every set of the burst but the last (set 1 at 0:00, sets 2 and 3 at 5:00: sets 1 and 2 get 2:30 each, and set 3 counts up from its tick; a third in the burst makes it three shares of 1:40). Sets with a rest of their own keep it and take no share, and unticking a set of the burst ends the sharing.
- **Tested between exercises:** the rest after the last set ticked off, in whichever exercise it was, is written when the next set is ticked in any exercise. This already worked in the service; the test now says so. Not seen on a phone.
